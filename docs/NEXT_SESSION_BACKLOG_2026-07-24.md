# Следующая сессия — зафиксированные задачи

Источник: ручное тестирование production 24 июля 2026 года. Этот список не означает, что проблемы уже исправлены.

## Приоритет 1 — сценарии голосования

1. [x] До открытия сбора поздравлений в блоке «Как это видит участник» не показывать кнопку «Открыть форму участника»: вместо неё вывести пояснение, что форма станет доступна после открытия сбора. Сейчас кнопка ведёт на `404`.
2. [x] После закрытия голосования участник должен видеть окончательно выбранный организатором вариант. Изменить голос или выбрать другой вариант в этом состоянии нельзя.

## Приоритет 2 — явные ошибки интерфейса

3. [ ] В сценарии создания открытки починить пустую кнопку «Как это работает». Отложено по решению пользователя.
4. [x] Убрать ручной выбор количества фото в блоке «Моменты»: всегда использовать 3 фото по умолчанию.
5. [x] Повторно открытая задача по шаблону «Маршрут» закрыта в `d9b5733`: fallback «С теплом, друзья» удалён, фактическая подпись подвала выводится рукописным шрифтом.

## Приоритет 3 — мобильная производительность и вёрстка

6. [x] На телефонах устранить заметную задержку при переключении схемы поздравления в создании открытки.
7. [ ] На телефонах проверить страницу участника (`join`): статусы, повод и связанные блоки не должны «разъезжаться». Вёрстка исправлена; нужен ручной прогон на реальном устройстве.
8. [x] Ускорить переключение между вкладкой «Поздравления и фото» и вкладкой «Оформление».

## Приоритет 4 — устойчивость AI

9. [x] Диагностировать единичную ошибку при определении качеств с помощью AI: исключение не перехватывалось в server action, поэтому страница попадала в error boundary. Добавлены повторное действие и журналирование `critical.ai`; исходную ошибку воспроизвести нельзя, так как открытка не сохранилась.

## Проверка после выполнения

- Пройти сценарии на desktop и реальном мобильном устройстве.
- Для голосования проверить состояния: сбор не открыт, сбор открыт, голосование открыто, голосование закрыто.
- Проверить, что переходы между вкладками не блокируют ввод и не создают заметных задержек.
