## Что закрывает текущий пакет

1. Общие security headers без запрета штатных same-origin iframe и Robokassa form action.
2. Лимиты создания открытки, отправки поздравления, AI-генерации и телеметрии. Ключ клиента хешируется; raw IP не хранится.
3. `/api/health`, расширенный production health-check и отдельная проверка свежести backup/диска.
4. Декодирование и повторное кодирование каждого нового JPG/PNG/WebP. Фактический формат важнее browser MIME; EXIF и прочие метаданные снимаются. Старые uploads не перекодируются и URL не меняются.
5. GitHub Actions с PostgreSQL 16, миграциями, typecheck, lint, coverage gate, build, Chromium/Firefox/WebKit smoke, артефактами скриншотов и production/dev audit.
6. Порог покрытия всего `src`: statements 48%, branches 42%, functions 46%, lines 49%. Это baseline-барьер от регресса, а не целевой потолок.
7. Исторический `/roadmap` редиректит на главную и закрыт в robots; `ROADMAP_BLOCKS.md` помечен как исторический.
8. Экспериментальная нейтрально-серая UI-палитра из пакета отменена после визуального сравнения. Редактор и публичные страницы сохраняют прежние тёплые бумажные поверхности; проверка `ui:colors` возвращена к действовавшему до эксперимента контракту.

## На что ещё обратить внимание

1. Текущий rate limiter живёт в памяти одного web-процесса и сбрасывается при restart. Для текущего одного контейнера это приемлемо; перед горизонтальным масштабированием нужен общий PostgreSQL/Redis-лимитер.
2. Нормализация защищает только новые uploads. Массовую переработку старых файлов не нужно делать без отдельного backup и плана rollback.
3. Первый пуш пакета должен подтвердить реальную работу GitHub Actions и установку трёх browser engines. Локально Chromium smoke не заменяет эту первую CI-приёмку.
4. CI сохраняет визуальные артефакты, но не падает по pixel-diff. Базовые скриншоты стоит зафиксировать отдельно после утверждения текущей возвращённой палитры, иначе база будет случайной.
5. CSP намеренно начинается с безопасных `object-src`, `base-uri`, `frame-ancestors` и `form-action`. Жёсткие `script-src`/`style-src` не включались без nonce-миграции, чтобы не сломать Next.js и consent-gated Метрику.
