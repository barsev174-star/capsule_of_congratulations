# AI-провайдеры

## Фактическая production-конфигурация на 29.08.2026

Все пользовательские AI-функции Slovesto обращаются напрямую к Yandex AI Studio через `https://ai.api.cloud.yandex.net/v1`:

- первичное поздравление участника на `/join`;
- варианты изменения подачи участником;
- создание поздравления организатором;
- сокращение и корректура поздравления организатором;
- выбор лучших цитат;
- формирование качеств получателя.

Основной сценарий создания текста возвращает один результат за одну AI-операцию. Дополнительные формулировки создаются отдельными действиями пользователя и сохраняются в истории интерфейса.

Production использует обязательную политику:

```env
PRODUCTION_PROVIDER_POLICY=russian-only
AI_PROVIDER=yandex
AI_GREETING_PROVIDER=yandex
AI_INSIGHTS_PROVIDER=yandex
YANDEX_COMPOSER_PLANNING=1
YANDEX_CLOUD_AI_BASE_URL=https://ai.api.cloud.yandex.net/v1
```

Модели задаются URI каталога Yandex Cloud. Секретные значения `YANDEX_CLOUD_API_KEY` и `YANDEX_CLOUD_FOLDER_ID` находятся только в `.env.production` на VPS и не сохраняются в Git.

## Защита от случайного возврата к прежним сервисам

При `PRODUCTION_PROVIDER_POLICY=russian-only` приложение разрешает только провайдер `yandex`. Значения `openai`, `routerai`, `gigachat` и `mock` завершаются ошибкой конфигурации до сетевого запроса. Production-проверка дополнительно требует пустые `OPENAI_API_KEY`, `ROUTERAI_API_KEY` и `GIGACHAT_AUTH_KEY`.

В репозитории остаются отдельные старые реализации и тестовые материалы для сравнения и истории разработки. Они не являются production fallback и не могут быть включены одной заменой переменной окружения. Возврат к ним потребовал бы отдельного изменения кода и нового релиза.

## Контроль качества

Yandex-сценарий разделяет извлечение фактов и композицию текста. Сервер проверяет лимит, лицо автора, форму обращения, обязательные факты и пожелания. Не прошедший проверку ответ не сохраняется как готовое поздравление и не расходует попытку пользователя.

Проверки перед выпуском:

```powershell
npm.cmd run providers:check
npm.cmd run ai:check
npm.cmd test -- --run src/lib/ai
npm.cmd run build
```

`providers:check` не отправляет текст модели и не показывает секреты. `ai:check` выполняет отдельный синтетический запрос напрямую к Yandex AI Studio и требует настроенный локальный ключ.

Подробности настройки каталога, сервисного аккаунта и Postbox: `docs/YANDEX_PROVIDER_MIGRATION_2026-08-28.md`.
