# Финальный просмотр открытки и выбор подарка

## Открытие открытки

- По кнопке «Посмотреть что внутри» всегда запускается анимация конверта. Если пользователь уже открывал эту открытку, повторный просмотр можно принудительно запустить из режима предпросмотра.
- В анимации используется уменьшенная версия настоящей открытки, а не техническая заглушка. На сгибе конверта остаётся один знак Slovesto — конверт, выровненный по центру.
- Кнопка «Создать такую же открытку» на финальной открытке ведёт к управлению текущей открыткой (`/manage/...`), а не к форме создания новой.

## Начало новой открытки

- Все общие призывы к созданию открывают управление черновиком: сервер создаёт пустую открытку только по явному нажатию кнопки и перенаправляет на `/manage/[manageToken]`.
- Для ссылок в письмах используется безопасный вход `/manage/new`: он не создаёт черновик при простом открытии страницы, а показывает кнопку «Открыть управление».
- Старый маршрут `/create` сохранён только для совместимости старых закладок и перенаправляет на `/manage/new`.

## Вертикальное фото в шаблоне Paper Birthday

- Вертикальное фото размещается под PNG-ассетом полароидной рамки: изображение закрывает область внутри рамки без видимых границ по краям.
- На широком экране рамка использует всю доступную ширину правой колонки, чтобы не оставлять пустое место рядом с фото.
- Подпись находится в нижней бумажной части ассета и занимает не более двух строк. Длинный текст обрезается, не выходя за пределы рамки.

## Выбор подарка

Доступны два режима:

- **Варианты подарков** — участники выбирают один из карточек товаров.
- **Сбор бюджета** — участники видят варианты сумм для общего подарка.

Режим меняется в модальном окне «Настройки голосования». Смена сценария удаляет текущие варианты (об этом предупреждает подсказка в окне) и доступна только до первого голоса.

### Черновик и публикация

- Добавление и редактирование вариантов происходит в модальном окне (на мобильном — полноэкранном): сначала импорт по ссылке или тексту магазина, затем ручная форма. Сервис извлекает доступные название, описание, цену и изображение; выбранная замена фото видна локально и загружается только после сохранения.
- Закрытие редактора с несохранёнными изменениями требует подтверждения «Закрыть без сохранения?». Порядок вариантов меняется перетаскиванием и пунктами меню строки; изменения порядка и состава сохраняются автоматически.
- Черновик может содержать от 0 до 6 вариантов: их можно свободно добавлять и удалять до первого голоса. Минимум два заполненных варианта требуется только для открытия голосования.
- Открыть голосование из черновика можно только после заполнения названия, вопроса и как минимум двух вариантов; условия проверяются и на сервере. Для ссылок на товары требуется `https://`. Перед открытием показывается подтверждение с чекбоксом о блокировке вариантов после первого голоса.
- После запуска фиксируется дата закрытия голосования. На публичной странице участника отображается только опубликованное голосование. После первого голоса варианты, их порядок, режим и тексты голосования заблокированы; дату завершения менять можно.

## Миграция

Для хранения времени закрытия используется миграция `0019_gift_poll_closed_at.sql`. В окружениях с PostgreSQL её нужно применить стандартной командой:

```bash
npm run db:migrate
```

## Проверка перед выпуском

1. Открыть финальную ссылку с чистой сессией, нажать «Посмотреть что внутри» и убедиться, что сначала проигрывается анимация.
2. Проверить вертикальное фото с короткой и двухстрочной подписью на desktop и мобильном экране.
3. В обоих режимах выбора подарка добавить несколько вариантов через модальное окно, закрыть редактирование и обновить страницу.
4. Проверить подтверждение с чекбоксом при открытии голосования и блокировку вариантов после первого голоса.
