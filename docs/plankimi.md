## 4. Сетка из трёх шаблонов

### `/example`

В `src/app/example/example.module.css`:

- на широком экране — три равные колонки в одной строке;
- до 900 px — две колонки;
- до 640 px — одна колонка;
- все три карточки должны иметь одинаковую ширину и высоту;
- ни одна карточка не должна растягиваться на всю строку;
- обнови `sizes` у миниатюр под треть ширины экрана;
- не используй `transition: all`.

Рекомендуемая схема:

```css
.templateGrid {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}

@media (max-width: 900px) {
  .templateGrid {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (max-width: 640px) {
  .templateGrid {
    grid-template-columns: minmax(0, 1fr);
  }
}

Главная страница
В src/app/_home/templates-section.tsx:
- замени текст один из двух на один из трёх;
- школьный шаблон тоже должен иметь ссылку на /example?template=school-scrapbook;
- список самих шаблонов продолжай получать через getCardTemplates();

- карточки должны оставаться одинаковой ширины;

- Фото сохраняют пропорции.
- На главной странице три шаблона находятся в одной строке на ПК.
- У школьной карточки на главной есть рабочая ссылка на её интерактивный пример.
- Мобильная версия не имеет горизонтального переполнения.
- Исходные PNG в docs сохранены без изменений.
- Чужие изменения в рабочем дереве не затронуты.
