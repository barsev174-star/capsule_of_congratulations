# Контроль индексации SEO-страниц Slovesto

Дата: 26.08.2026. Контролируются четыре страницы:

- `/gruppovaya-otkrytka/uchitelyu`;
- `/gruppovaya-otkrytka/vospitatelyu`;
- `/gruppovaya-otkrytka/kollege`;
- `/gruppovaya-otkrytka/den-rozhdeniya`.

## Автоматическая техническая проверка

Команда `npm run seo:indexing:check` проверяет production:

- HTTP 200, title, один H1, self-canonical и отсутствие `noindex`;
- BreadcrumbList и FAQPage;
- наличие и доступность `og:image`;
- присутствие всех четырёх URL в `/sitemap.xml`;
- ссылку на sitemap и отсутствие запрета SEO-раздела в `/robots.txt`.

Эта проверка подтверждает техническую доступность для робота, но не факт включения страницы в поисковый индекс.

## Однократная настройка — выполнена 26.08.2026

### Google Search Console

1. Подтвердить domain property `slovesto.ru` или URL-prefix property `https://slovesto.ru/`.
2. Добавить `https://slovesto.ru/sitemap.xml` в раздел Sitemaps.
3. Через URL Inspection проверить четыре адреса и запросить индексацию отсутствующих страниц один раз. Повторные запросы не ускоряют обход.

Выполнено: URL-prefix ресурс `https://slovesto.ru/` подтверждён HTML-тегом, `/sitemap.xml` отправлен, все четыре страницы приняты в приоритетную очередь индексирования. Первичная обработка нового ресурса и sitemap выполняется Google асинхронно.

Официальные инструкции: [отправка sitemap](https://support.google.com/webmasters/answer/7451001) и [запрос повторного обхода](https://developers.google.com/search/docs/crawling-indexing/ask-google-to-recrawl).

### Яндекс Вебмастер

1. Подтвердить сайт `https://slovesto.ru`.
2. Добавить `https://slovesto.ru/sitemap.xml` в «Индексирование → Файлы Sitemap».
3. Проверить четыре адреса и отправить отсутствующие на переобход.

Выполнено: сайт подтверждён, sitemap уже обрабатывается, все четыре страницы приняты в очередь переобхода 26.08.2026 в 17:22.

Официальная инструкция: [файлы Sitemap в Яндекс Вебмастере](https://yandex.ru/support/webmaster/ru/indexing-options/sitemap). Яндекс указывает, что обработка нового sitemap может занимать до двух недель; наличие URL в sitemap не гарантирует его попадание в поиск.

## Еженедельный контроль

Отчёт формируется по понедельникам и содержит:

1. Технический статус четырёх страниц, robots, sitemap и OG.
2. За 7 дней и для контекста за 30 дней: просмотры SEO-страниц, переходы в пример, нажатия создания, созданные открытки, открытки с поздравлением, подтверждённые оплаты, передачи и открытия.
3. Разрез по четырём страницам и строку «Без SEO-атрибуции».
4. Количество participant-отправок и критических ошибок без персональных данных.
5. Статус Search Console и Яндекс Вебмастера только по данным этих кабинетов. Оператор `site:` не считается надёжным подтверждением индексации.
6. Три коротких вывода: что изменилось, где проблема, какое одно действие нужно следующим.

Автоматизация `Еженедельный отчёт Slovesto` активна и запускается по понедельникам в 10:00 по локальному времени проекта. Каждый запуск создаёт отдельную локальную задачу и работает только на чтение.

Оплаты считаются только по подтверждённому серверному журналу согласно `ACQUISITION_ANALYTICS_2026-08-26.md`.

## Когда реагировать

- Немедленно: HTTP не 200, noindex, неправильный canonical, страница исчезла из sitemap, сломан OG или SQL отчёта.
- После 14 дней: поисковая система всё ещё не обнаружила страницу — проверить кабинет, URL Inspection/проверку URL, внутренние ссылки и журнал обхода.
- После 4 недель: есть показы, но нет кликов — переработать title/description под реальные запросы.
- После накопления достаточного трафика: есть клики, но нет созданий — проверить первый экран, интент и CTA; новый SEO-лендинг до этого не выпускать.
