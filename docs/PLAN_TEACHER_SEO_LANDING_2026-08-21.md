# Технический план: SEO-landing «Открытка учителю от класса»

Дата: 21 августа 2026 года.

Статус на 24 августа 2026 года: реализовано и принято. Финальная версия использует `school-classic`, отдельный teacher-specific create action, first-touch attribution и изолированные `data-teacher-reveal` атрибуты. Сценарий `/gruppovaya-otkrytka/uchitelyu` → `/example?template=school-classic` → Back проверен в живом браузере: все 42 reveal-узла видимы, конфликтов с глобальным `[data-reveal]` нет.

Исходное ТЗ: пользовательский документ «SEO-посадочная страница “Групповая онлайн-открытка учителю от класса”».

Связанное дизайн-ТЗ: [TZ_KIMI_TEACHER_LANDING_2026-08-21.md](./TZ_KIMI_TEACHER_LANDING_2026-08-21.md).

## Решение

ТЗ подходит продукту и текущей архитектуре, но реализуется как три согласованных слоя:

1. SEO и серверная страница;
2. first-touch attribution и связь с существующей продуктовой воронкой;
3. presentation-слой, адаптив и визуальная приёмка.

Новая страница не меняет управление, оплату и recipient experience. `school-classic` используется как доказательство продукта и начальный шаблон teacher-specific черновика.

## Зафиксированные технические решения

| Вопрос | Решение |
| --- | --- |
| Публичный URL | `/gruppovaya-otkrytka/uchitelyu` без завершающего слеша |
| Canonical | `https://slovesto.ru/gruppovaya-otkrytka/uchitelyu` |
| Почему без `/` | В `next.config.ts` не включён `trailingSlash`; не менять глобальное поведение сайта ради одной страницы |
| Rendering | Server Component; ключевой текст, заголовки, ссылки и FAQ присутствуют в исходном HTML |
| Пример | Ссылка `/example?template=school-classic`; не встраивать тяжёлый recipient experience в landing |
| Создание | `startTeacherCardFromShowcaseAction` создаёт обычный черновик с начальным `templateId = school-classic`; общий CTA главной остаётся нейтральным |
| Prefill | Не добавлять: безопасного существующего prefill-механизма сейчас нет |
| Основной CTA | Создаёт пустой черновик и открывает `/manage/[manageToken]` |
| Schema | `BreadcrumbList` и `FAQPage`; не добавлять отзывы, рейтинг и availability |
| Сезонность | Отдельный маленький контентный объект; на запуске — «К 1 сентября» |
| First-touch | Без новой таблицы: cookie до создания, затем attribution записывается в существующее событие `funnel.card_created` с `cardId` |
| Оплата | Использовать существующие `payment_orders` / `payment_events`, соединяя их с `telemetry_events` по `cardId`; не создавать дублирующее событие оплаты |

## Подтверждённый продуктовый контракт

- создание и участие без регистрации;
- до 100 поздравлений;
- фотографии добавляет организатор;
- до 7 фотографий;
- создание, сбор, настройка, модерация и preview доступны до оплаты;
- финальная подготовка и передача — 399 ₽ единоразово;
- подписки нет;
- оплаченная открытка хранится не менее 12 месяцев;
- школьный пример доступен через продуктовый `school-classic`.

Не обещать автоматическую компоновку результата без участия организатора. Организатор выбирает фотографии, управляет содержанием, проверяет результат и определяет момент вручения.

## Компактная структура страницы

Исходные смысловые требования сохраняются, но пересекающиеся блоки объединяются. На мобильном должна получиться продуктовая landing page, а не длинная SEO-статья.

### 1. Hero и сезонный контекст

- eyebrow: `Открытка от учеников и родителей`;
- H1: `Групповая онлайн-открытка учителю от всего класса`;
- текст: `Соберите личные поздравления учеников и родителей по одной ссылке, добавьте фотографии класса и превратите всё в одну красивую открытку для учителя.`;
- основной CTA: `Собрать открытку учителю`;
- вторичный CTA: `Посмотреть пример`;
- подпись: `Без регистрации · Сбор бесплатно · До 100 поздравлений · 399 ₽ только перед вручением`;
- сезонная плашка: `К 1 сентября` и короткий текст из исходного ТЗ;
- визуал: фрагмент готового `school-classic`, не редактор и не административный интерфейс.

### 2. Слова каждого

Заголовок: `Не одна подпись «от всего класса», а слова каждого`.

Три коротких голоса: ученик, родитель, выпускник. Блок одновременно объясняет отличие от общей формальной подписи и сообщений в чате.

Финальная строка: `Из разных голосов складывается живой портрет учителя глазами класса.`

### 3. Как это работает

Заголовок: `Одна ссылка для всего класса`.

Четыре шага:

1. создать открытку;
2. отправить ссылку в чат;
3. собрать личные поздравления;
4. оформить, проверить и подарить.

Визуальная цепочка: `организатор → ссылка → класс → открытка → учитель`.

### 4. Из поздравлений получается подарок

Объединяет исходные блоки про результат, роль организатора и сравнение с потоком сообщений.

Заголовок: `Поздравления не остаются списком сообщений`.

Показать:

- фотографии класса;
- качества учителя;
- особенно тёплые фразы;
- поздравления каждого;
- единое оформление;
- контроль результата одним организатором.

### 5. Центральный интерактивный пример

Заголовок: `Посмотрите открытку глазами учителя`.

- крупный визуальный фрагмент школьной открытки;
- CTA `Открыть пример открытки` → `/example?template=school-classic`;
- следующий CTA `Сделать такую для нашего учителя` → существующее создание;
- не загружать полный интерактивный рендерер внутри landing.

### 6. Кто участвует и кто добавляет фотографии

Объединяет учеников, родителей, весь класс и фотографии.

- ученики и родители добавляют личные слова;
- организатор выбирает и добавляет фотографии;
- примеры фотографий: 1 сентября, экскурсии, поездки, праздники и обычные совместные дни;
- лимит 7 фотографий не делать главным маркетинговым сообщением.

### 7. Поводы

Заголовок: `Для важных моментов в течение всего учебного года`.

1 сентября, День учителя, окончание года, последний звонок, выпускной, юбилей и благодарность классному руководителю. Не делать из элементов ссылки на несуществующие страницы.

### 8. Цена

Заголовок: `Сначала соберите открытку — платить заранее не нужно`.

- до оплаты: создание, приглашение, сбор, настройка, фотографии, модерация и preview;
- после готовности: `399 ₽ один раз`;
- пояснение: `Без подписки и регулярных платежей`;
- финальная мысль: `Сначала убедитесь, что открытка получилась. Оплачивайте только когда будете готовы её вручить.`

### 9. FAQ

Использовать вопросы из исходного ТЗ:

1. нужна ли регистрация;
2. нужно ли приложение;
3. могут ли участвовать ученики и родители;
4. кто добавляет фотографии;
5. можно ли проверить поздравления;
6. сколько человек может участвовать;
7. нужно ли оплачивать заранее;
8. для каких школьных поводов подходит;
9. как учитель получит открытку.

Один и тот же массив вопросов используется для видимого UI и `FAQPage` JSON-LD.

### 10. Финальный CTA

- заголовок: `Соберите слова класса, которые учителю захочется сохранить`;
- текст: `Создать открытку можно сейчас, а приглашать учеников и родителей — когда будете готовы.`;
- CTA: `Собрать открытку учителю`;
- подпись: `Без регистрации · Начать бесплатно`.

## First-touch attribution

### Какие данные сохраняются

- `landing_type = teacher`;
- `landing_path = /gruppovaya-otkrytka/uchitelyu`;
- `utm_source`;
- `utm_medium`;
- `utm_campaign`;
- безопасно нормализованный `referrer_host`;
- время первого касания.

Не сохранять полный referrer URL, query referrer, имена, email, поздравления, secret/manage/join/gift URL и любой пользовательский контент.

### Механизм

1. Небольшой client-компонент landing при первом открытии читает только разрешённые UTM-параметры и `document.referrer`.
2. Если first-touch cookie отсутствует, записывает cookie `slv_first_touch` на 90 дней с `SameSite=Lax`, `Path=/` и `Secure` в production.
3. Cookie не перезаписывается последующими landing-посещениями.
4. Для известных поисковых referrer host без UTM нормализует source/medium как `yandex|google` / `organic`.
5. `startTeacherCardFromShowcaseAction` читает cookie, передаёт attribution в создание черновика и фиксирует начальный `school-classic`; общий `startCardFromShowcaseAction` сохраняет прежнее нейтральное поведение.
6. `funnel.card_creation_started` и существующее `funnel.card_created` получают одинаковый attribution context.
7. `createEmptyCardDraft` принимает опциональный безопасный funnel context; домашний сценарий продолжает работать без него.
8. Если JavaScript или cookie недоступны, создание открытки всё равно работает; теряется только attribution.

Cookie должна иметь строгий parser, ограничение длины и allowlist значений. Невалидная cookie игнорируется и не должна ломать CTA.

### События landing

- `seo_landing_view`: `landing_type`, `landing_path`;
- `seo_create_click`: `landing_type`, `landing_path`, `placement`;
- `seo_example_click`: `landing_type`, `landing_path`, `template = school-classic`.

Допустимые `placement`: `hero`, `middle`, `final`, `example`. CTA в header относится к `hero`.

Расширить client event allowlist и разрешённые context keys в `src/lib/telemetry.ts`. Сохранить ограничение длины строк. Не передавать произвольный объект из клиента без фильтрации.

### Воронки

Ранний KPI:

`funnel.card_created[landing_type=teacher] → funnel.participant_link_copied` по `card_id`.

Бизнес-KPI:

`funnel.card_created[landing_type=teacher, medium=organic] → payment_orders.status=PAID` по `card_id`.

Для preview, доставки и открытия использовать существующие фактические источники данных. Не создавать события-дубликаты только для того, чтобы вся воронка находилась в одной таблице.

## Производительность и доступность

- hero image является LCP: `next/image`, реальные размеры, корректный `sizes`, без lazy loading;
- изображения ниже первого экрана загружаются лениво;
- не подключать motion-библиотеку;
- основной текст не зависит от client rendering;
- изображения готовой открытки имеют содержательный alt, декор — пустой alt;
- заголовки идут H1 → H2 → H3;
- touch targets от 40×40 px, предпочтительно 44×44 px;
- focus-visible заметен и не зависит только от цвета;
- поддержать `prefers-reduced-motion`;
- не использовать `transition: all` и `will-change: all`;
- H1/H2/H3 используют `text-wrap: balance`, короткие описания — `text-wrap: pretty`;
- изображения получают внутренний outline `1px solid rgba(0, 0, 0, 0.1)`;
- CTA при нажатии использует `scale(0.96)`;
- вложенные близкие поверхности используют концентрические радиусы.
