# Упрощённые фотоблоки во вкладке «Оформление»

Статус реализации на 31 июля 2026 года: завершено.

## Границы ответственности вкладок

- «Оформление» отвечает за состав открытки, вид блока и краткую готовность.
- «Поздравления и фото» отвечает за загрузку, назначение и изменение фотографий.
- В «Оформлении» не показываются селекты фотографий, миниатюры, порядок снимков и счётчики «доступно».

## Блок «Поздравления»

- В свёрнутом состоянии показываются описание и статус готовности.
- После раскрытия по умолчанию показывается компактное резюме выбранной компоновки.
- Кнопка «Изменить вид» раскрывает существующие варианты компоновки.
- Для варианта с фотографиями показывается только «Выбрано X из Y» и переход к секции фотографий поздравлений.
- Для варианта без фотографий действие назначения фотографий не показывается.
- Если блок готов и раскрыт, внизу показывается кнопка «Готово — свернуть блок».
- Кнопка закрывает редактор вида и сворачивает блок сразу, без обновления страницы.

## Блок «Моменты»

- Текст блока по умолчанию представлен компактным резюме.
- «Изменить текст» раскрывает поля заголовка и описания.
- Фотографии представлены только статусом «Выбрано X из Y» и переходом к секции «Моменты».

## Переходы во вкладку контента

Поддерживаются прямые URL, работающие в том числе после перезагрузки:

- `?tab=content&focus=main-congratulation`;
- `?tab=content&focus=congratulations-photos`;
- `?tab=content&focus=moments-photos`.

После загрузки страницы целевая секция прокручивается в видимую область, а её заголовок получает клавиатурный фокус.

## Проверки

- Компонентные тесты проверяют X/Y, отсутствие селектов и миниатюр, а также focus-ссылки.
- Readiness-тесты проверяют специализированные статусы блоков.
- Интерфейс проверен на ширинах desktop 1280, 1366, 1440 и 1600 px.
- Интерфейс проверен на ширинах mobile 360, 375, 390 и 430 px.
