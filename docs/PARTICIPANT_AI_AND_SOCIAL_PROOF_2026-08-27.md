# AI-помощник и social proof на странице участника

Дата фиксации: 27 августа 2026 года. Статус: реализовано локально, production-деплой не выполнялся.

## Итоговый пользовательский сценарий

Страница `/join/[slug]` сохраняет одну форму поздравления и один вход в AI — кнопку «Помочь с текстом» рядом со счётчиком символов. Первый запрос создаёт только один вариант семейства `main` («Основной»). Остальные тексты появляются только после отдельного подтверждённого действия пользователя и расходуют по одной AI-попытке.

Созданные результаты хранятся в трёх независимых семействах:

- `main` — основной и альтернативные варианты из тех же мыслей;
- `warm` — более тёплая подача без новых фактов;
- `creative` — более свободная композиция с одной допустимой образной деталью.

В каждой семье хранится история. Вкладка появляется только после первой успешной генерации этой семьи; при нескольких версиях доступны стрелки и счётчик `N из M`. Выбор вкладки, раскрытие действия и навигация по истории не вызывают API и не расходуют попытку.

## Операции AI

| Действие в интерфейсе | Операция API | Куда сохраняется результат |
| --- | --- | --- |
| Помочь с текстом | `initial` | новый `main`, при новом исходном черновике история начинается заново |
| Теплее | `warmer` | новая версия `warm` |
| Творческий | `creative` | новая версия `creative` |
| Другой вариант | `alternative` | новая версия `main` |
| Раскрыть подробнее | `expand` | новая версия активного семейства |
| Сделать короче | `shorten` | новая версия активного семейства |
| Создать вариант с деталями | `initial` + `requiredDetail` | новая версия `main`; все прежние версии сохраняются |

Действие по длине показывается контекстно: короткому тексту предлагается раскрытие, близкому к лимиту — сокращение. Во время запроса текущий результат и история остаются на экране. Ошибка показывается локально с повтором того же запроса; параллельные генерации блокируются идентификатором активного запроса.

Дополнительная деталь ограничена 300 символами, пустое или состоящее из пробелов значение не отправляется. Деталь добавляется к пользовательским заметкам, попадает в semantic plan как обязательный `user-detail` и программно проверяется на сохранность. Общий AI-черновик участника ограничен 700 символами; старый лимит 1500 символов сохраняется только для отдельного сценария сокращения.

## Компоновка и accordion

На desktop используются две независимые вертикальные колонки: слева форма и сразу под ней «Уже добавили», справа AI-панель. Следующая полноширинная секция начинается после более высокой колонки. Форма не растягивается до высоты AI-панели.

На mobile порядок фиксирован: форма → AI-помощник → «Уже добавили» → готовая открытка. В AI-панели одновременно раскрывается только одно действие или форма деталей; повторное нажатие сворачивает его. Тексты действий пользовательские, без терминов внутренней AI-реализации.

## Privacy-превью «Уже добавили»

Блок является social proof, а не просмотром чужих сообщений. Сервер получает только видимые поздравления и перед передачей в клиент строит отдельное preview:

- первые три слова;
- не более 32 Unicode-символов;
- нормализованные пробелы;
- многоточие только при наличии продолжения.

Полный текст поздравления в компонент карусели не передаётся. Превью отображается одной строкой без tooltip и без возможности раскрытия. Имя и необязательная роль автора остаются видимыми; badge показывает количество видимых поздравлений.

## Карусель

На desktop помещаются три карточки, на mobile — одна карточка с частью следующей. Автоперелистывание запускается раз в 5 секунд, только когда есть скрытая следующая карточка: больше трёх поздравлений на desktop или больше одного на mobile.

Автоперелистывание приостанавливается при hover, фокусе, активном касании и скрытой вкладке, затем продолжается с текущей позиции. Desktop дополнительно имеет стрелки, mobile поддерживает swipe. `aria-live="off"`; дубликаты бесконечного цикла скрыты от accessibility tree.

При `prefers-reduced-motion` таймер сохраняется, но переход выполняется без плавной анимации. Это осознанное отступление от первоначального ТЗ: после ручной приёмки пользователь отдельно потребовал сохранить автоматическую смену и на ПК, и на mobile. Живой тест при активном системном reduced-motion подтвердил смену через 5 секунд на 1440 px и 390 px.
