# Переработка вкладки «Поздравления и фото»

Статус: реализовано и проверено локально 31 июля 2026 года как промежуточный этап.

> Итоговая навигация описана в `FOUR_EDITOR_SECTIONS_2026-07-31.md`: «Поздравления» и «Фотографии» больше не являются подразделами общей вкладки, а открываются как самостоятельные основные разделы. Старые URL с `tab=content&section=...` сохранены только для обратной совместимости.

## Что изменено

1. Внутри вкладки появились самостоятельные подразделы «Поздравления» и «Фотографии». Одновременно монтируется только активный редактор.
2. Активный подраздел хранится в URL через `section=congratulations|photos`. Прямые ссылки, обновление страницы, переходы назад и ссылки из «Оформления» сохраняют нужный контекст.
3. «Поздравления» получили отдельную рабочую область:
   - компактное главное поздравление;
   - локальный поиск по имени, роли и тексту;
   - фильтры с реальными количествами;
   - компактные свёрнутые карточки;
   - существующие редактирование, видимость, выбор главного, AI и порядок внутри раскрытой карточки.
4. На широком экране рабочая сетка совпадает с вкладкой «Оформление»: гибкая основная колонка и контекстная колонка 380 px без вложенной прокрутки.
5. «Подготовка открытки» и «Ссылка для участников» используют реальные состояния карточки и на узких экранах переходят в общий поток.
6. На мобильном добавлена одна нижняя контекстная кнопка. Переход к настройке открывает первый незавершённый блок «Оформления», раскрывает его и прокручивает к нему.
7. Редактор фотографий перенесён в отдельный подраздел без изменений API и модели данных.

## Поведение фотографий

Механика загрузки не менялась: новая фотография автоматически занимает первый свободный слот в существующем порядке. Организатор по-прежнему может изменить назначение или поменять фотографии местами. Нового состояния «не назначено» и параллельного назначения при загрузке не добавлено.

## Проверки

- `npm.cmd run lint`;
- модульные тесты URL-навигации, поиска и фильтрации;
- `npm.cmd run build`;
- browser smoke на тестовой открытке:
  - переключение подразделов и обновление URL;
  - восстановление подраздела кнопкой «Назад»;
  - клавиатурные стрелки и перенос фокуса;
  - переход «Изменить» к главному поздравлению;
  - локальный поиск;
  - отсутствие горизонтального переполнения на 360, 390, 430, 768, 1024, 1280, 1440 и 1920 px.

## Границы задачи

Карточки, слоты и форма загрузки фотографий не перерабатывались глубоко. Формат итоговой открытки, серверная модель и существующие API не менялись.
