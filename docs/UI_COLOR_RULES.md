# Цвета интерфейса

Зафиксированное продуктовое правило: коричневый цвет в интерфейсе не используется.

| Назначение | Цвет |
| --- | --- |
| Основной текст | `#202124` |
| Вторичный текст | `#5f6368` |
| Приглушённый текст | `#8a9099` |
| Основное действие | `#e9652f` |
| Наведение на основное действие | `#df5f2e` |
| Нажатие основного действия | `#c7532a` |
| Основная поверхность | `#ffffff` |
| Нейтральная поверхность | `#f7f8fa` |

Основные кнопки должны быть сплошными оранжевыми. Вторичные кнопки остаются белыми или нейтральными, но используют оранжевый текст и/или рамку. Обычный текст — графитовый или серый.

Перед завершением UI-доработки нужно выполнить `npm run ui:colors`. Проверка просматривает стили приложения и завершится ошибкой, если обнаружит коричневый цвет текста или элемента управления.

Художественная палитра внутри изображения или готовой открытки не задаёт палитру интерфейса редактора.
